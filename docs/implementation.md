# AirDB Hong Kong — homepage

## Agreed scope
Independent Astro project adapted from airdb.io, English with Traditional and Simplified Chinese. Presentation only: cross-border trade, authorized Agent payments, x402 and micropayments. No live payment APIs, wallets, credentials or sandbox. No claims of regulatory approval, live e-CNY access, partners or settlement performance.

## Implementation plan
1. Copy the latest airdb.io main configuration, lockfile, licensed fonts and design tokens; omit Git history and legacy content.
2. Implement a shared localized homepage with navigation, four scenarios, authorization controls, a static x402 flow, a clear roadmap and email contact.
3. Set airdb.hk domain, canonical/alternate links, sitemap, robots and GitHub Pages workflow.
4. Install frozen dependencies, build all three routes and check desktop/mobile rendering, navigation and metadata.

## Verification focus
Language links work without JavaScript; mobile navigation remains accessible; protocol examples visibly simulated; no old domain/product claims; no horizontal overflow; no forms pretending to submit.
